# স্টোরি রিডার — ল্যান্ডিং পেজ

বাংলাদেশের পাঠকদের জন্য তৈরি একটি আকর্ষণীয়, পূর্ণ-বাংলা ল্যান্ডিং পেজ যেখানে ব্যবহারকারীরা গল্প পড়া, লাইক ও কমেন্ট, গল্প সেভ, এবং দৈনিক সাবস্ক্রিপশন (মাত্র ২ টাকা + ভ্যাট) সম্পর্কে জানতে পারবেন — এবং এক ক্লিকে APK ডাউনলোড করতে পারবেন।

## বৈশিষ্ট্য

- সম্পূর্ণ বাংলা ভাষায় কন্টেন্ট এবং মুদ্রা ৳ টাকায়
- হিরো, ফিচার, কীভাবে কাজ করে, সাবস্ক্রিপশন, মতামত, প্রশ্নোত্তর, ফাইনাল CTA, ফুটার
- লাইভ অ্যানিমেশন (রিভিল অন স্ক্রল, কাউন্টার, প্যারালাক্স, ফোন মকআপ)
- মোবাইল রেসপন্সিভ, ডার্ক গ্রেডিয়েন্ট থিম, গ্লাসমরফিজম কার্ড
- এক ক্লিকে সার্ভার থেকে APK ডাউনলোড

## সার্ভার / ডাউনলোড কনফিগারেশন

`script.js` ফাইলের শুরুতে সার্ভার সেট করা আছে:

```js
const BASE_URL = 'https://www.bdappsdigitalapps.com/NADB26020/story_reader';
const APK_FILENAME = 'Story_Reader.apk';
const APK_URL = `${BASE_URL}/${APK_FILENAME}`;
```

ডাউনলোড বাটনে ক্লিক করলে সরাসরি এই URL থেকে APK ডাউনলোড হবে:
`https://www.bdappsdigitalapps.com/NADB26020/story_reader/Story_Reader.apk`

## ফাইলসমূহ

- `index.html` — মূল পেজ (সম্পূর্ণ বাংলা)
- `styles.css` — স্টাইল ও অ্যানিমেশন
- `script.js` — ইন্টারঅ্যাকশন ও ডাউনলোড লজিক

## কীভাবে চালাবেন

যেকোনো ওয়েব সার্ভার যেমন `Live Server` (VS Code), `python -m http.server`, অথবা সরাসরি `index.html` ফাইলটি ব্রাউজারে ওপেন করে দেখতে পারবেন।

```bash
# পাওয়ারশেল থেকে
cd "c:\Users\user\Desktop\Story Reading app\Landing page"
python -m http.server 8000
# এরপর ব্রাউজারে: http://localhost:8000
```

## সাবস্ক্রিপশন নীতি

- মূল্য: **২ টাকা + ভ্যাট / দিন**
- ব্যবহারকারী যেকোনো সময় আনসাবস্ক্রাইব করতে পারবে
- কোনো লুকানো চার্জ নেই
